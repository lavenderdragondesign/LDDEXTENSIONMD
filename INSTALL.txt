WELCOME
LDD Tools is an optional workflow enhancement extension for MyDesigns. It adds faster access to common tools, workflow shortcuts, visual customization, performance controls, and optional creator utilities while keeping MyDesigns as the underlying platform.

INSTALL / UPDATE
1. Extract the ZIP to a NEW folder. Do not run the extension from inside the ZIP.
2. In Chrome, open chrome://extensions
3. Turn Developer mode ON.
4. If updating from an older unpacked build, remove the old LDD Tools entry first to avoid Chrome loading stale files.
5. Click Load unpacked.
6. Select the extracted LDD Tools folder — the folder containing manifest.json.
7. Open or reload MyDesigns.

DEFAULT MODE
Power User is the default mode for fresh installs.
Lite mode remains available inside LDD Tools -> Settings.
Existing saved settings are preserved when possible.

DRAG & DROP UPLOAD — IMPORTANT
LDD Drag & Drop uses MyDesigns' native Upload Designs workflow.

- Drag & Drop uploads go to your DEFAULT FIRST SLOT, regardless of what that slot is named on your account.
- LDD passes the dropped files to the native MyDesigns "Drag and drop files" area and waits for MyDesigns to enable Start Uploading.
- If you are adding multiple designs to a SINGLE LISTING, use the DEFAULT MYDESIGNS UPLOAD SYSTEM. DO NOT use LDD Drag & Drop for that workflow.
- If MyDesigns changes its uploader markup or behavior, Drag & Drop may require an LDD update.

CAROUSEL RENAMER
The renamer works with the designs LDD detects as selected/checked in MyDesigns. Always review the detected selection and resulting names before continuing a large rename job.

SCOUT AI
Scout AI Style Creator & Autofiller is optional and can be enabled, disabled, or opened from the Tools page.

CHATGPT PROMPT QUEUE
The ChatGPT Prompt Queue is optional and is OFF unless enabled. It only runs on supported ChatGPT pages when enabled.

PERFORMANCE / TINYMD
Performance controls are optional.
TinyMD is intentionally aggressive and may reduce animations, effects, or nonessential interface behavior to maximize responsiveness. Save important work before using aggressive performance options.

GITHUB UPDATE CHECKER
---------------------
LDD Tools can check a public GitHub repository's latest Release and notify you when a newer version is available.
Updates use the official Lavender Dragon Design GitHub release source automatically. No repository setup is required.
For downloadable updates, attach the LDD Tools ZIP as a .zip asset to the GitHub Release.
Because this is loaded as an unpacked Chrome extension, LDD Tools cannot overwrite its own source folder. The updater downloads the ZIP; extract it over the same LDD Tools folder and click Reload on chrome://extensions. Your chrome.storage settings remain in the extension profile.

UPDATES
-------
LDD Tools checks official GitHub Releases from lavenderdragondesign/LDDEXTENSIONMD.
When an update is found, use the in-app download button, extract the update over your existing LDD Tools folder, then click Reload on chrome://extensions.
